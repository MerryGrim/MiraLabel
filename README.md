# MiraLabel — Мятная студия

Статический лендинг по выбранному макету Mira Mint. Репозиторий содержит сайт и размещает готовые файлы приложения в GitHub Releases; исходный код Windows-приложения здесь не публикуется. Работает на GitHub Pages без сборки: HTML, CSS, JavaScript и локальные изображения/SVG. Русский, английский и упрощённый китайский; светлая и тёмная темы. Настройки хранятся только в браузере. Аналитики, внешних шрифтов и CDN нет.

## Локальный просмотр

Запустите любой статический HTTP-сервер из этой папки и откройте его адрес. Например, при установленном Python: `python -m http.server 8080`. Открытие через `file://` не подходит: браузер блокирует загрузку локальных JSON-файлов.

## Релиз и публикация

Единственный источник метаданных скачивания — `release.json`: версия, имена, размеры, SHA-256 и **прямые проверенные HTTPS-ссылки на файлы GitHub Release**. До публикации оба `downloads.*.url` и `releaseUrl` должны быть заполнены. Значение `null` означает, что ссылка ещё не подтверждена, и загрузка отключается.

Разместите содержимое папки в корне репозитория GitHub Pages. Файл `.nojekyll` отключает обработку Jekyll. Все внутренние пути относительные, поэтому страница работает и в `username.github.io/repository/`.

Снимки настоящего редактора 0.2.6 находятся в `assets/editor-*.webp`. Смена языка переводит интерфейс приложения на снимке; содержание примера этикетки остаётся частью пользовательского макета. Протокольные возможности других моделей не заявляются. В тексте сохранено требование проверить текущую сборку на своём D11H.

SVG Lucide 0.468.0 взяты из закреплённого набора приложения и официального коммита `f12b0de177fbc2a6795e99be065887e72b237123`. Источники и хэши: `assets/icons/manifest.json`. Уведомления: `licenses/LUCIDE-LICENSE.txt`.

Изменения сайта вносите непосредственно в `index.html`, `assets/site.css` и `assets/site.js`. Сборка и установка зависимостей не требуются.
